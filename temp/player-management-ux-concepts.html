How the selection flow works

The same room list supports all three choices without hiding what is playing in each room. The builder is a draft until the user applies it.

01 · RECALL

Saved room groups

Choose a named preset such as “Whole home” or “Downstairs,” or delete it from its row. Deleting a preset does not stop or unsync current players.

02 · ARRANGE

Temporary group

Drag a connected player onto Current selection to add it. Use the group builder to remove rooms or save the selection as a preset.

03 · SELECT

One room or many

Tap any individual room to switch to single-player control. The selection banner always names the active room or group.

04 · SCAN

Track subtitles

Show the current title and artist on every player row, with playback/connectivity state kept secondary and easy to scan.

LMS API notes

JSON-RPC 1.0 · /jsonrpc.js

Requests use the existing slim.request wrapper. Global queries use player ID 0; player-specific calls use the player ID returned by players_loop.

POST /jsonrpc.js
{"id":1,"method":"slim.request","params":["0",["players",0,100]]}

For each connected player, request status with the current track fields. LMS returns the current queue item in playlist_loop; Lyriamp can fall back to current_title.

{"id":1,"method":"slim.request","params":["<player-id>",["status","-",1,"tags:aclKN"]]}

Live membership is queried from a player with sync ?; the response lists its group members, or - if it is solo. Add each member to a chosen leader with sync; unsync a room with sync -.

{"id":1,"method":"slim.request","params":["<player-id>",["sync","?"]]}
{"id":1,"method":"slim.request","params":["<leader-id>",["sync","<member-id>"]]}
{"id":1,"method":"slim.request","params":["<player-id>",["sync","-"]]}
LMS exposes live sync membership, not named saved presets. A preset should be stored locally by Lyriamp and applied as a sequence of sync calls. When joining, LMS may move a member out of its previous sync group; verify the result with the player-specific sync ? query. LMS also provides syncgroups ? for a server-wide listing.

References: JSON-RPC request format · players, sync, and syncgroups commands
